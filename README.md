# Magnificent Desolation

A multiple-star system planet mod for Kerbal Space Program.

Dependencies: 
* Kopernicus (and its prerequisites) 
* Kopernicus Expansions
* VertexMitchellNetravaliHeightmap

Magnificent Desolation is a modular planet pack. The central black hole, Auox, is the core of the mod. The rest of the modules add planets to each of the stars.

Current mods are:
* MagDes_Core (Auox the black hole, and all of the stars (without planets)
* MagDes_Haun (A beginner-friendly orange dwarf system, the main home system.)

MagDes is intended as a System Replacer that removes the Kerbol System, but in future there may be an interstellar destination patch that makes it an additional system visitable from Kerbin.
